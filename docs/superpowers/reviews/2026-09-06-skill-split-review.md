# spec 검진 기록 — 스킬 쪼개기 (2026-09-06)

검토 대상은 `docs/superpowers/specs/2026-09-06-skill-split-design.md`다. 렌즈를 한 번씩만 돌렸다. 한 서브에이전트가 grounding과 consistency를 차례로 적용했고, adversarial은 자세가 반대라 따로 띄웠다. 렌즈 원본은 이 파일과 같은 이름의 폴더에 있다. 선행연구 렌즈는 제안하지 않았다. 이미 있는 스킬을 다시 나누는 일이라 발동 기준에 걸리지 않는다.

## 이 회차가 뒤집은 것

검진이 spec의 **근거** 다섯을 무너뜨렸다. 고쳐 쓸 것이 문안이 아니라 판단이라, 이 spec은 부분 수정 대신 다시 쓴다.

| 무너진 근거 | 실제 |
|---|---|
| 공식 `pdf`에 `pdftoppm`이 없다 | 공식 `pdf`가 함께 나르는 `reference.md`에 쪽 범위를 준 예제가 셋 있다. 본문만 보고 단정했다 |
| "Extract specific pages"는 파일을 자르는 것이다 | `pdftotext`로 1–5쪽 텍스트만 꺼내는 예제다. 쪽을 고르는 행위 자체는 공식에 있다 |
| markitdown은 우리 몫이다 | 공식 `xlsx`와 `pptx`가 본문에서 이미 읽기 수단으로 든다 |
| 구형 오피스 변환은 우리 몫이다 | 공식 `pptx`와 `docx`가 `soffice`로 다룬다 |
| 공용에 갈 분량이 약 60줄이다 | 73줄이다 |

"내용은 한국어와 사내 몫만 남긴다"는 결정은 그대로 두더라도, 무엇이 그 몫인지를 다시 재야 한다. 겹치는 자리가 생각보다 넓다.

## 설계를 바꿔야 하는 지적

| 지적 | 렌즈 | 왜 중요한가 |
|---|---|---|
| 설명 문안을 정하는 자리가 spec에 없다 | adversarial | 매 세션 실리고 열림을 결정하는 것이 설명뿐이다. 목적으로 내건 것이 산출물에 없었다 |
| CSV 작업이 우리 스킬을 하나도 안 거친다 | adversarial | 공식 `xlsx` 설명이 `.csv`를 담고, 우리 CSV 규칙은 좁게 쓸 공용에 있다. cp949 문제가 그대로 돌아온다 |
| 이름 겹침의 위험은 사람의 혼동이 아니다 | adversarial | 공식 설명이 배타적 명령문으로 끝나 우리 것이 안 열릴 수 있다 |
| 쪼갠 뒤가 더 비쌀 수 있다 | adversarial | 한국어 발표자료 한 건이 스킬 셋을 열면 지금 332줄을 넘는다 |
| `docx`에 담을 것을 재기 전에 여섯으로 확정했다 | adversarial·consistency | 재 보고 남는 것이 없으면 머리말뿐인 스킬이 설명 자리를 차지한다 |
| `xlsx`에 남는 것이 12줄이다 | adversarial | 함께 필요한 CSV 규칙은 공용으로 뗀다 |
| 절 사이 상호 참조 세 문장이 깨진다 | adversarial | 순서 2단계가 그 문장을 고치는 것을 금지한다 |
| `hwp`만 두 형식군을 담는다 | consistency | 형식으로 가른다는 기준과 어긋난다 |

## 사실이 틀렸던 곳

`setup.ps1`의 두 자리와 `tests/test_setup.ps1`의 한 자리가 `document-formats`를 플러그인이 나르는 스킬 이름으로 부른다. spec은 "설치기 코드에서는 개인 폴더 이름으로만 쓰인다"고 적었다. 셋 다 주석이라 테스트는 깨지지 않지만 고칠 곳 계산이 틀렸다.

그 밖에 공용 줄 수(60→73), 지금 설명 길이(400자→327자), 공식 `pptx`의 안전한 글꼴 수(둘→일곱), `docx` 실측 인용의 요소 모양이 실제와 달랐다.

## 처분

다시 쓰기로 했으므로 지적을 하나씩 반영하지 않는다. 대신 다시 쓸 때 지켜야 할 것을 남긴다.

- 설명 여섯을 먼저 쓰고 그것을 산출물로 삼는다.
- 설명이 공식과 경쟁하지 않고 동행하게 쓴다. "공식 X와 **함께** 반드시 연다"를 명령문으로 박는다.
- 공용의 설명이 좁으면서 CSV와 인코딩을 이름으로 단다.
- `claude plugin eval`로 실제로 열리는지 잰다. 채점기가 `tool_used: Skill`을 본다. 열리지 않는 설명은 내보내지 않는다.
- 공식과 겹치는 자리를 절마다 다시 대조한다. 본문만 보지 말고 함께 나르는 참조 파일까지 연다.
- 쪼갠 뒤의 비용을 쪼개기 전과 나란히 적는다.

## 렌즈가 남긴 확인거리

이미 깔린 플러그인에 재설치가 무엇을 하는지, 스킬이 여섯일 때 `claude plugin validate`가 무엇을 보는지는 렌즈가 확인하지 못했다. 다시 쓸 때 잰다.
